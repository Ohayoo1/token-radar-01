A token launch radar: it reads a sealed DefiLlama protocol snapshot and ranks the protocols that
record no token yet by the value a token would imply if the protocol's record stayed as it is,
with a farm plan per protocol, a readable dashboard and a reproducible dossier.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```

`main.ts` (Node 22, standard library only) reads `/input/snapshot.json` (or `--input <file|dir>`),
writes `/output/board.json`, `/output/data.js`, copies `dashboard/` and `screenshots/` into
`/output`, and writes `/output/dossier.json` with `vendor/makefun-board.ts`.
